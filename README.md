# QuantX

## Quantitative Multi-Asset Financial Intelligence & Backtesting Platform

QuantX is a FinTech research platform for analyzing historical market data across:

- Gold
- Bitcoin
- NVIDIA
- S&P 500

### Features

- SMA and EMA analysis
- Returns analysis
- Volatility
- Sharpe ratio
- Maximum drawdown
- Correlation analysis
- Quantitative strategy backtesting
- Transaction costs
- Portfolio allocation
- Monte Carlo simulation
- Market regime analysis
- Quantitative research report

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- SciPy
- yfinance
- OpenAI API (optional)

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
